Spektrum Deutsch A1+ Interactive Study App — v2.5.0
===================================================

Open index.html to study locally. No server is required for the core app.

v2.5.0 changes
--------------
- English-first study mode by default (Arabic helper boxes turned off by default; can still be toggled in Settings).
- Restored and upgraded Word Review & Shadowing Lab: practise flashcards with Spaced Repetition (Again / Hard / Good), switch between Words (493 items) and Phrases/Sentences (526 items), filter by chapter, listen at normal or slow (0.68x) speed, and record your own pronunciation.
- Activated the built-in German letters keyboard dock (ä, ö, ü, ß, Ä, Ö, Ü, €) so you can insert umlauts and Eszett into any exercise or vocabulary test input with one click.
- Fixed missing CSS --accent variable so Missing Letters underlines and active Start Deutsch 1 page borders render clearly in both Light and Dark themes.
- Upgraded automatic exercise checking (CORRECTION_KEYS): R/F (richtig/falsch) and A/B/C multiple-choice questions now render interactive clickable pill buttons instead of plain text boxes.
- Fixed Vocabulary States on the Progress page to track both lexical Words and Phrases/Sentences accurately.
- Audited and cleaned 390+ automated DING dictionary glosses and filtered out 111 OCR fragments/personal names in Discovered Words.
- Added missing PWA icons (assets/icon-192.png, assets/icon-512.png), wired Service Worker registration, and removed duplicate data/content.json payload.
